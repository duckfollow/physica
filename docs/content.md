# สิ่งที่มีใน Physica ตอนนี้

Physica เป็นสื่อจำลองภาษาไทย เน้นปรับตัวแปรแล้วเห็นผล ครอบคลุมฟิสิกส์ ชีววิทยา เคมี และคณิตศาสตร์

แต่ละการจำลองมีคำถามชวนสังเกต ทฤษฎีสั้น ๆ สมการ นักวิทยาศาสตร์ที่เกี่ยวข้อง ขอบเขตแบบจำลอง และคำถามชวนทดลอง

ในคลังการจำลองจัดกลุ่มตามวิชา และมีป้าย “แนะนำ” สำหรับจุดเริ่มต้น ในโหมดขยายสื่อการสอนจะเหลือแถบสังเกตกับบุคคลสำคัญบนจอ

| เส้นทาง | เนื้อหา |
| --- | --- |
| `/simulations/` | รายการการจำลองทั้งหมด 62 เรื่อง |
| `/simulations/<id>/` | หน้าทดลองแต่ละเรื่อง |
| `/learn/` | เลือกการจำลองตามระดับผู้เรียน |
| `/tutor/` | หน้า placeholder สำหรับ AI tutor ในอนาคต |
